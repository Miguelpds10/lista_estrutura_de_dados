Exercício 9 - Palíndromo de Pilha

a) Teste com arara, osso, java e a.
Resposta:

arara é palíndromo? true
osso é palíndromo? true
java é palíndromo? false
a é palíndromo? true

b) Por que a pilha resolve esse problema com naturalidade? Qual característica dela é aproveitada
aqui?
Resposta: A pilha resolve este problema com naturalidade porque, 
ao empilhar as letras da esquerda para a direita e depois desempilhá-las, 
os caracteres saem na ordem inversa (do último para o primeiro). 
A característica aproveitada é o comportamento LIFO (Last In, First Out / "o último a entrar é o primeiro a sair").

c) Qual capacidade a pilha precisa ter? Crie-a com o tamanho certo a partir da palavra recebida
Resposta:  A pilha precisa de ter uma capacidade igual ao número de caracteres da palavra que está a ser testada (ou seja, palavra.length()). 
Ela é criada na classe de teste definindo o seu tamanho a partir da String recebida: "Pilha pilha = new Pilha(palavra.length());" .
